# 100만 원 미국 주식 분리 운용

작성: 2026-09-12. 개발 기준: `main` 커밋 `6be27da5e8ba64d3f1ae162855b05c06f063c3bb`.

2026-09-14 갱신: [AI 실행 감사 및 학습 안내](AI_RUNTIME_AUDIT_20260914.md)에
모델 학습·JSON 저장·명시적 로딩 경로와 이번 결함 수정 결과를 기록했습니다.
기본값은 여전히 미학습 규칙이며 검증된 실데이터 모델은 제공되지 않습니다.
`model-train`, `model-inspect`, `AIPRO_US_MODEL_PATH`와 `AIPRO_US_MODEL_SHA256`을
사용할 수 있습니다. 입력 누락·오래된 프레임은 진단/단일 실행에서 실패로 표시합니다.

이 변경은 기존 AiPro에 **실행 가능한 로컬 모의 운용**을 추가합니다. 실제 주문을 전송하지 않으며, 학습된 수익 예측 모델이나 검증된 투자 성과를 제공하는 단계는 아닙니다. 기존 뉴스·거시경제·공시·시장 지표와 모델 검증 구성 요소를 재사용합니다.

## 확정한 자금 원칙

| 항목 | 구현한 규칙 |
|---|---|
| 외부 지원금 | 최초 1,000,000원. 동일 장부에 추가 입금하는 경로는 차단 |
| 단타 | 200,000원, 미국 주식 전용 |
| 장기 | 800,000원, 미국 주식 전용 |
| 재투자 | 각 자금에서 발생한 비용 차감 후 실현 수익과 결제 완료 현금만 사용 |
| 손실 | 잔고가 감소한 상태를 그대로 유지. 재시작·날짜 변경으로 돈을 다시 채우지 않음 |
| 자금 전용 | 단타와 장기 사이, 코인과 미국 주식 사이의 묵시적 이동 없음 |
| 차입 | 신용·미수·공매도·레버리지 주문 기능 없음 |
| 평가이익 | 표시에는 반영하지만 평가이익만큼 매수 한도를 늘리지 않음 |
| 현금 유보 | 각 자금의 위험 계산 기준금액 중 최소 5%를 현금으로 남김 |

가용 매수금액은 결제 현금, 현재 평가액, 최초 배정금액에 누적 실현손익을 더한 금액, 기존 매수원가, 포지션 한도 중 가장 엄격한 조건으로 제한합니다. 새로운 테스트 DB는 별도 가상 계좌입니다. 실제 여러 계좌의 입금 상한을 보장하려면 계좌 식별자와 증권사 거래내역을 연결한 별도 검증이 필요합니다.

## 전략과 중단 기준

아래 수치는 검증을 시작하기 위한 설계 기본값이며 최적 수치라는 의미는 아닙니다.

| 항목 | 단타 | 장기 |
|---|---|---|
| 매수 판단 | 거래량 증가, VWAP 상회, 가격 돌파, 상승 추세/시장 상황 | 이전에 완성된 일봉 200개, 가격 > 50일 평균 > 200일 평균 |
| 점검 주기 | 매 입력 시점 | 7일마다 신규 매수·추세 재점검 |
| 최대 보유 | 2종목 | 4종목 |
| 하루 신규 진입 | 최대 3회, 동일 종목 재진입 제한 | 보유 수와 현금 한도 내 |
| 한 종목 상한 | 자금의 47.5% 이내 + 거래당 위험 한도 | 자금의 25% 이내 |
| 거래당 위험 예산 | 기준 자금의 0.5%, 초기 1,000원 | 단타 위험 예산 미적용 |
| 당일 손실 중단 | -1%, 초기 약 2,000원에서 HALT·청산 시도 | 단타 일일 기준을 적용하지 않음 |
| 당일 수익 중단 | 예상 청산 비용을 차감한 평가액이 +2%이면 청산·추가 진입 중단 | 일일 수익 목표 없음 |
| 개별 포지션 | -1.5% 손절, +3% 익절, 상승 후 1.2% 추적 손절 | -12% 포지션 손절, 중요 공시 위험, 주간 추세 이탈 |
| 장 마감 | 정규장 종료 5분 전부터 청산 시도 | 유지 가능 |

단타 최고 평가액 대비 -6% 또는 미국 주식 두 자금 합계의 최고 평가액 대비 -10%에서 중단 상태를 유지합니다. 전체 중단은 두 자금 모두 청산을 시도합니다. 거래 정지, 시세 누락, 장 마감, 갭 하락, 유동성 부족 때는 즉시 청산할 수 없으므로 **손절 설정이 최대 손실을 보장하지 않습니다.** 부분 체결로 남은 수량은 청산 사유를 저장해 다음 유효한 시세에서 재시도합니다.

단타 20만 원의 2%는 **4,000원**입니다. 총 100만 원에서 하루 2만 원을 벌도록 강제로 위험을 높이는 설계가 아닙니다. 장기 수익률과 단타 수익률은 서로 다른 분모로 계산합니다. 매수 조건이 없거나 온전한 1주를 살 수 없으면 현금을 유지합니다. 소수점 매수는 정책 설정과 종목의 지원 여부가 모두 확인된 경우만 허용하며 기본값은 꺼져 있습니다.

## 기존 실행 구조와 연결

`run.py -> telegram.py -> main.py -> TradingApplication`

- 기존 `CRYPTO` 실행 경로는 유지합니다.
- `AIPRO_RUNTIME=US_DUAL`이면 `aipro/us_stocks/portfolio_application.py`를 생성합니다.
- 미국 주식 장부는 `data/us_dual_paper.sqlite3`를 사용합니다. 코인 DB를 지정하면 거부합니다.
- `portfolio_policy.py`: 금액·거래·위험 정책.
- `portfolio_market.py`: 시점별 시세, 환율, 거래일, 뉴스·거시경제·공시 입력과 결합 지표 연결.
- `portfolio_strategy.py`: 두 전략과 선택적 예측 모델 연결.
- `portfolio_ledger.py`: SQLite 원자적 상태 저장, 자금 대사, 변경 불가 감사 기록.
- `portfolio_replay.py`: 합성 데모와 시점 순서 재생.

기존 `build_market_feature_snapshot`, `classify_regime`, `build_combined_paper_feature_vector`, `validate_paper_strategy`와 EV/변동성 사이징·체결 비용 시뮬레이터를 재사용합니다. `intelligence_from_components`는 기존 뉴스·FRED·SEC·시장 스냅샷을 받아 적격성·시점·출처 지문을 확인한 뒤 운용 입력으로 변환합니다. 공급자 데이터를 자동으로 채우거나, 누락된 분석을 중립으로 지어내지 않습니다.

기본값에는 학습 모델이 연결되지 않습니다. 규칙 점수는 승률이 아닙니다. 검증된 모델을 연결하려면 `ForecastProvider.forecast(quote, feature_fingerprint)`를 구현해 기존 `ForecastEvidence`를 반환해야 합니다. 모델을 선택했는데 예측이 없거나 지표 지문이 다르면 규칙 모델로 우회하지 않고 매수를 거부합니다. 기존 XGBoost/LightGBM/CatBoost 및 시계열 모델 학습·비교 기능은 연구 영역에 남아 있으며, 자동으로 이 실행기에 배포되지 않습니다.

Python 3.11~3.13 환경에서:

```bash
python -m aipro portfolio-demo
python -m aipro portfolio-demo --output data/us_dual_demo_report.json
python -m pytest -q -W error tests/test_us_dual_portfolio.py tests/test_combined_features.py
```

`SIMS`, `SIML`은 가상 입력 식별자입니다. 가격·환율·뉴스 상태·거래일은 소프트웨어 테스트를 위해 만든 값이며 실제 종목 추천이나 백테스트 성과가 아닙니다. 데모 장부는 임시 경로에 생성하므로 운영 장부와 섞이지 않습니다. 보고서는 항상 `live_ready=false`, `qualifies_as_elapsed_paper_evidence=false`를 표시합니다.

## 시점별 데이터 재생

```bash
python -m aipro portfolio-replay data/us_frames.jsonl --output data/us_replay_report.json
```

각 줄은 `MarketFrame.to_dict()` 형식의 JSON 하나입니다. 시점은 엄격히 증가해야 하며, 역순·중복 시점을 정렬해서 숨기지 않습니다. 보유 종목 시세 누락이나 데이터 오류는 보고서와 실패 종료 코드에 남깁니다. 재생은 임시 장부와 입력 시점의 시계를 사용합니다. 데이터 지문과 정책 지문, 체결, 관측한 최대 낙폭, 최종 잔고를 보고합니다. 배당 포함 벤치마크와 비교하는 전체 투자 성과 검증은 아직 별도입니다.

## 반복 모의 운용

`config/us_dual_paper.env.example`의 값을 로컬 `.env`에 반영하고 시세 공급기가 입력 파일을 갱신하도록 준비합니다.

```bash
python -m aipro doctor --require-pytest
python run.py
```

- `AIPRO_PAPER_INTERVAL_SECONDS=0`: 한 번 실행.
- `1~60`: 반복 간격. 실제 간격에는 분석 시간과 Telegram 대기 시간이 추가됩니다.
- `AIPRO_US_FRAME_PATH`: 공급기가 임시 파일 작성 후 원자적으로 교체하는 JSON 입력 파일.
- Telegram 토큰과 허용 채팅 ID를 설정하면 `/status`, `/portfolio`, `/run_once`, `/halt`, `/go` 사용 가능.
- `/halt`는 즉시 중단 상태를 저장합니다. 청산은 다음 유효한 거래 사이클이 필요합니다.
- `/go`는 최신 평가와 위험 기준을 다시 확인합니다. 당일 손실 기준금액이나 수익 목표 중단을 지우지 않습니다.
- 장부 정책 지문이 다르면 자동으로 초기화하지 않습니다. 정책 변경에는 기록을 보존하는 명시적 마이그레이션이 필요합니다.

현재 시세/증권사 자동 수집 어댑터는 이 새 실행기에 연결되지 않았습니다. 입력 파일이 없으면 그 이유를 표시하고 거래하지 않습니다. 기존 Alpaca PAPER API는 별도 구성 요소이며, 이 실행기가 그 API에 주문을 보내지는 않습니다.

## 입력의 의미

| 필드 | 의미와 요구 사항 |
|---|---|
| `as_of_utc` | 평가·체결 시점, 시간대 필수, 실제 반복 운용에서는 최대 60초 지연 |
| `usd_krw`, `fx_as_of_utc` | 양수인 관측 환율, 최대 300초 지연 |
| `session_open_utc`, `session_close_utc` | 실제 거래일 달력의 미국 정규장 개장·폐장. DST·휴장·조기폐장 반영 필요 |
| `settlement_at_utc` | 해당 매도 대금이 사용 가능해지는 미래 시점. 공급기가 증권사 결제 규칙으로 계산 |
| `quotes` | 최대 100개, 보유 종목을 모두 포함, 고유 티커와 신선한 bid/ask 및 주식 수 단위 호가 잔량 |
| `intraday_bars` | 이 세션에서 이미 완성된 봉. 시간은 봉의 사용 가능 시점이며 체결 시점보다 이전이어야 함 |
| `daily_bars` | 서로 다른 날짜의 완성된 일봉. 당일 미완성 봉 사용 금지 |
| `intelligence` | 실제 관측 시점, 뉴스 점수, 거시 위험, 검토한 중요 위험, 출처. 없으면 새 매수 거부 |
| `synthetic` | 합성 여부. 합성·비합성 입력을 같은 장부에 섞으면 거부 |

JSON의 출처 문자열이나 SHA-256은 신뢰성·서명을 보증하지 않습니다. 종목–CIK 연결, 공급자 인증, 휴일·결제일과 시세 단위 검증은 실제 어댑터가 책임져야 합니다. 현재 프레임은 휴일표를 자체적으로 다운로드하지 않으며, 규칙에 맞는 평일 입력이 실제 개장일임을 증명하지 않습니다.

## 손익·비용과 검증 한계

- 현금은 가상 KRW 장부이며 체결 때마다 USD 가격을 관측 환율로 환산합니다. 실제 USD 계좌 잔고와 아직 대사하지 않습니다.
- 매수·매도 각각 거래 수수료 0.1%, 환전 비용 0.1%, 불리한 체결 방향으로 슬리피지 0.05%를 기본 가정합니다. bid/ask 차이도 별도로 반영합니다. 실제 증권사 요율이 아닙니다.
- 한 번 환전한 USD를 유지하는 실제 계좌와 다르므로 비용을 과대 추정할 수 있습니다. 세금, 배당, 주식 분할·합병에 따른 장부 조정은 미구현입니다. 장기 전략을 실제 장기간 검증하기 전에 반드시 추가해야 합니다.
- 모의 체결은 표시된 호가 잔량 안에서만 계산하고 동일 프레임에서 두 자금이 잔량을 공유합니다. 실제 주문 대기열·취소·거래소 체결을 재현하지 않습니다.
- 일일 기준은 KST 날짜별로 두 자금에 따로 저장합니다. 정확한 00:00 관측이 없으면 마지막 관측 평가액을 다음 기준으로 사용해 야간 변동을 숨기지 않습니다. 따라서 항상 정확한 자정 평가액을 보장하는 것은 아닙니다.
- 모든 프레임이 실패한 재생, 잘못된 지표, 미학습 기본 전략은 수익성 증거가 아닙니다. 합성 결과와 경과한 실제 모의거래 일수를 합산하지 않습니다.

2. 배당·분할·합병 장부 처리, 실제 비용·세금, 원시 데이터 보관과 시점 일치 검증을 추가. 장기 전략은 배당 포함 벤치마크와 별도 평가.

기본 실행에는 Python 표준 라이브러리만 필요합니다. GPU는 필요하지 않습니다. 개발·테스트는 Linux/Python 3.12에서 확인하며, 3.11~3.13은 저장소 CI 대상으로 유지합니다. 운영 장비 용량은 종목 수와 데이터 보관 기간에 따라 측정해야 하므로 이 코드만으로 서버 사양이나 월 비용을 확정하지 않습니다.
